Как сделаю

  1. Сервер — беседы вместо одной лички. Одна сущность conversation с видом dm / group / channel; участники с ролями owner / admin / member / subscriber; у каждого участника свой курсор прочтения (счётчики), mute, pin, archive — на сервере, чтобы браузер и десктоп видели одно. Сообщения: reply_to, edited_at, удаление, реакции, закрепы. Нынешние личные диалоги переезжают в эту модель как dm без потерь.
  2. Шифрование. Личка — как сейчас, ключи хранилища. Группа — сквозное: ключ группы, зашифрованный на ключ хранилища каждого участника; при удалении участника ключ меняется. Публичный канал — посты подписаны автором и читаются без хранилища; закрытый канал — как группа.
  3. Папки — в аккаунте на сервере: имя, иконка, включённые типы и чаты, исключения, порядок.
  4. Реальное время — один поток событий на сессию (SSE): новые сообщения, правки, прочтения, «печатает», онлайн. Тот же поток, что нужен шерингу пресетов для живой синхронизации — делается один раз для обоих. Опрос остаётся запасным.
  5. Доступ по лестнице: писать — как сейчас в личке; создавать группы и каналы — paid и выше; модерация публичных каналов — moderator / admin.
  6. Клиент. Новый макет (папки, список, чат), группировка сообщений, меню правого клика, панель на наведении, выделение и копирование, поле ввода с ответом / правкой / @, док хранилища, только токены темы; затем группы, каналы, папки, диалоги создания; затем карточки графиков и пресетов в чате, реакции, «печатает» и онлайн.
  7. Батчи. 0.5.615 — баг выделения текста в личке (механизм в коде есть с 2d9cc157, у тебя не работает) и золото → токены. Мессенджер целиком — отдельным батчем: сервер (беседы, папки, поток событий) + клиент (макет, группы, каналы, папки) выходят вместе одним релизом, не частями.

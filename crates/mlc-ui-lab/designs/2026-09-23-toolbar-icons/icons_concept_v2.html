Toolbar icons — concept v2 (2026-09-23)

v1 was a plain comparison table the owner found unclear. This concept places the same icons where they actually live — the left rail, the Smart Money / Order Flow flyouts, the right toolbar — plus a full before/after detail grid per icon in both theme presets. Icon bodies for the Smart Money, Order Flow, Autodetector-rail and Right-toolbar groups are the coordinator's v2 set (icons_v2.json), used byte-for-byte.

Why the "before" column ever looked wrong: until now uzor's SVG renderer ignored the opacity attribute entirely, so every intended tint in the current icons rendered as a solid block — that is why the smart-money icons look heavier than they were drawn. Uzor commit 9cee4ea adds opacity and dash support, so the "before" side below is shown two ways: painted (opacity stripped — exactly what today's app renders) and as authored (the intended tint, invisible until this fix lands). The new set: 24 px grid, 1.5 px stroke, tints at ~20% opacity, and every scan tool wears one shared motif — range brackets [ ] around the family glyph, reading as "drag over a range".
